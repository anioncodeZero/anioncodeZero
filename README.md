# WebGuard Scanner

Web security scanner built with Python and Flask.

## Features

- Website crawling
- Security header analysis
- Technology detection
- Port scanning
- Subdomain discovery
- Scan history
- SQLite database

## Tech Stack

Python • Flask • SQLite • BeautifulSoup
